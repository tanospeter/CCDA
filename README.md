# CCDA

**Combined Cluster and Discriminant Analysis 1.2 R package**

CRAN publication is currently in progress.

---

## Documentation for package ‘ccda’ version 1.2

### Functions

* **`ccda.main`**: Combined Cluster and Discriminant Analysis
* **`percentage`**: Calculation of the ratio of correctly classified cases by linear discriminant analysis
* **`plotccda.cluster`**: Plot of the basic grouping
* **`plotccda.q95`**: CCDA density drawer
* **`plotccda.results`**: Plot of the results of `ccda.main`
